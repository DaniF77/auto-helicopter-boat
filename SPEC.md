## 1. Назначение

Автовертолодка — трёхрежимное средство передвижения: лодка, которая по необходимости выезжает на берег как автомобиль и поднимается в воздух как вертолёт. Рассчитана на одного пилота. Основной режим — плавание, а езда и полёт нужны, чтобы обойти преграды. Каждое переключение режима стоит энергии, а полёт самый затратный.

## 2. Стихия и конструкционный элемент

Стихия: вода.

Конструкционный элемент: герметичный корпус-лодка, создающий плавучесть.

Как реализован элемент:

> Корпус имеет объём `hull_volume_m3`. Вода выталкивает 1000 кг на каждый кубометр объёма корпуса. Если `mass_kg > hull_volume_m3 * 1000`, автовертолодка тонет и плавать (движение в режиме воды) не может.

Ограничения стихии:

- Стартовый режим — плавание (`"water"`).
- Езда (`"ground"`) и полёт (`"air"`) доступны, но дороже по энергии.
- Плавать может только транспорт, у которого корпус держит его массу.

## 3. Публичный интерфейс

### 3.1. Класс и исключения

Модуль: `auto_helicopter_boat.py`

Класс: `AutoHelicopterBoat`

Доменные исключения (все определены в модуле `auto_helicopter_boat.py`, наследуются от `Exception`):

- `BoatSinks` — корпус не держит массу, плавать нельзя.
- `BoatWrongMode` — транспорт в другом режиме, чем требуется для движения.
- `BoatOutOfEnergy` — энергии недостаточно.

### 3.2. Конструктор

```python
def __init__(
    self,
    name: str,
    mass_kg: float,
    hull_volume_m3: float,
    max_speed_kmh: float,
    energy: float = 100.0,
) -> None:
```

| Параметр | Тип | Единица | Допустимый диапазон | По умолчанию |
|---|---|---|---|---|
| name | str | — | непустая строка | — |
| mass_kg | float | кг | > 0 | — |
| hull_volume_m3 | float | м³ | > 0 | — |
| max_speed_kmh | float | км/ч | > 0 | — |
| energy | float | условные единицы | 0 … 100 (границы включены) | 100.0 |

Исключения конструктора:

- `ValueError` — если `name` пустой.
- `ValueError` — если `mass_kg`, `hull_volume_m3` или `max_speed_kmh` ≤ 0.
- `ValueError` — если `energy` вне диапазона 0…100.

Начальное состояние: `mode == "water"`, `position_km == 0`.

Транспорт, у которого `mass_kg > hull_volume_m3 * 1000`, создаётся без ошибки. Он утонет только при попытке плыть (см. 3.4.2).

### 3.4. Методы

#### Общие константы режимов

| Режим | Скорость | Расход энергии на 1 км | Стоимость переключения В этот режим |
|---|---|---|---|
| `"water"` | `max_speed_kmh * 0.5` | 1 | 2 |
| `"ground"` | `max_speed_kmh * 0.8` | 1.5 | 5 |
| `"air"` | `max_speed_kmh * 1.0` | 3 | 10 |

#### 3.4.1. switch_mode

```python
def switch_mode(self, new_mode: str) -> None:
```

Назначение: переключает режим транспорта.

Параметры: `new_mode` — `"water"`, `"ground"` или `"air"`.

Возвращает: `None`.

Изменяет: `mode`, `energy`, `is_flying`.

Исключения:

- `ValueError` — если `new_mode` не из списка.
- `BoatOutOfEnergy` — если `energy` меньше стоимости переключения. Состояние не меняется.

Правила:

- Порядок проверок: сначала допустимость `new_mode`, потом энергия.
- Стоимость берётся из столбца «Стоимость переключения» по **новому** режиму.
- Если `new_mode == mode`, ничего не происходит, энергия не тратится.
- Энергия ровно равна стоимости — переключение разрешено (энергия станет 0).

#### 3.4.2. move

```python
def move(self, distance_km: float, terrain: str) -> float:
```

Назначение: перемещает транспорт на заданное расстояние по указанной среде.

Параметры:

- `distance_km` — расстояние в км, > 0.
- `terrain` — среда: `"water"`, `"ground"`, `"air"`.

Возвращает: время движения в часах (`distance_km / скорость режима`).

Изменяет: `position_km` (увеличивается на `distance_km`), `energy` (уменьшается на `distance_km * расход режима`).

Исключения (в порядке проверки):

1. `ValueError` — если `distance_km` ≤ 0.
2. `ValueError` — если `terrain` не из списка.
3. `BoatWrongMode` — если `terrain != mode`.
4. `BoatSinks` — если `terrain == "water"` и `mass_kg > hull_volume_m3 * 1000`.
5. `BoatOutOfEnergy` — если `energy` меньше затрат.

При любом исключении состояние транспорта не меняется.

Правила:

- Скорость и расход берутся из таблицы режимов.
- Если `mass_kg == hull_volume_m3 * 1000`, корпус ещё держит массу, `BoatSinks` не возникает.
- Если `energy` ровно равна затратам, движение разрешено (энергия станет 0).

#### 3.4.3. calculate_energy

```python
def calculate_energy(self, distance_km: float, terrain: str) -> float:
```

Назначение: считает затраты энергии на движение, ничего не меняя.

Параметры: те же, что у `move`.

Возвращает: `distance_km * расход режима terrain`.

Исключения: `ValueError` — если `distance_km` ≤ 0 или `terrain` не из списка.

Правила: текущий режим, масса и запас энергии на результат не влияют. Состояние не меняется.

#### 3.4.4. can_overcome

```python
def can_overcome(self, obstacle: str) -> bool:
```

Назначение: проверяет, может ли транспорт преодолеть препятствие в **текущем режиме**.

Параметры: `obstacle` — `"wall"`, `"river"`, `"tree"`.

Возвращает: `True` / `False`.

Исключения: `ValueError` — если `obstacle` не из списка.

Правила:

- `"wall"` — только в режиме `"air"`.
- `"river"` — в режимах `"water"` и `"air"`; в `"ground"` нельзя.
- `"tree"` — в режимах `"ground"` и `"air"`; в `"water"` нельзя.

#### 3.4.5. refuel

```python
def refuel(self, amount: float) -> None:
```

Назначение: пополняет энергию.

Параметры: `amount` — количество энергии, > 0.

Возвращает: `None`.

Изменяет: `energy`, но не выше 100.

Исключения: `ValueError` — если `amount` ≤ 0.

#### 3.4.6. get_status

```python
def get_status(self) -> dict:
```

Назначение: возвращает снимок состояния.

Возвращает: словарь с ключами:

- `"name"` — str,
- `"energy"` — float,
- `"position_km"` — float,
- `"mode"` — str,
- `"is_flying"` — bool,
- `"hull_volume_m3"` — float.

## 4. Сценарии

Во всех сценариях, если не сказано иное: `mass_kg = 500`, `hull_volume_m3 = 1`, `max_speed_kmh = 100`, `energy = 100`. Скорости: вода 50, земля 80, воздух 100 км/ч.

### Сценарий 4.1. Высадка на берег

Дано: свежая автовертолодка, режим `"water"`.
Когда:

1. `move(10, "water")`;
2. `switch_mode("ground")`;
3. `move(20, "ground")`.

Тогда:

- шаг 1 вернул 0.2 ч, энергия 90;
- шаг 2: энергия 85;
- шаг 3 вернул 0.25 ч, энергия 55;
- итог: `position_km == 30`, `energy == 55`, `mode == "ground"`.

### Сценарий 4.2. Полёт через стену

Дано: свежая автовертолодка.
Когда:

1. `switch_mode("air")`;
2. `can_overcome("wall")`;
3. `move(20, "air")`;
4. `switch_mode("water")`;
5. `can_overcome("wall")`.

Тогда:

- шаг 1: `is_flying == True`, энергия 90;
- шаг 2: `True`;
- шаг 3 вернул 0.2 ч, энергия 30;
- шаг 4: `is_flying == False`, энергия 28;
- шаг 5: `False`;
- итог: `position_km == 20`, `energy == 28`, `mode == "water"`.

### Сценарий 4.3. Утонувшая автовертолодка

Дано: `hull_volume_m3 = 0.4` (корпус держит 400 кг, масса 500 кг).
Когда:

1. `move(5, "water")`;
2. `switch_mode("ground")`;
3. `move(10, "ground")`.

Тогда:

- шаг 1: `BoatSinks`, `position_km == 0`, `energy == 100`;
- шаг 2: энергия 95;
- шаг 3 вернул 0.125 ч;
- итог: `position_km == 10`, `energy == 80`.

### Сценарий 4.4. Не хватило энергии на взлёт

Дано: `energy = 12`.
Когда:

1. `switch_mode("air")`;
2. `move(1, "air")`;
3. `refuel(50)`;
4. `move(1, "air")`.

Тогда:

- шаг 1: энергия 2;
- шаг 2: `BoatOutOfEnergy`, `energy == 2`, `position_km == 0`;
- шаг 3: энергия 52;
- шаг 4 вернул 0.01 ч, энергия 49, `position_km == 1`.

### Сценарий 4.5. Полный круг

Дано: свежая автовертолодка.
Когда:

1. `switch_mode("air")`, `move(10, "air")`;
2. `switch_mode("ground")`, `move(10, "ground")`;
3. `switch_mode("water")`, `move(20, "water")`;
4. `can_overcome("river")`;
5. `get_status()`.

Тогда:

- энергия по шагам: 90, 60, 55, 40, 38, 18;
- шаг 3 вернул 0.4 ч на последнем `move`;
- шаг 4: `True`;
- шаг 5: `{"name": <имя>, "energy": 18, "position_km": 40, "mode": "water", "is_flying": False, "hull_volume_m3": 1}`.

### Сценарий 4.6. Лес и река

Дано: свежая автовертолодка.
Когда: пилот по очереди проверяет `can_overcome("river")`, `can_overcome("tree")`, `can_overcome("wall")` в режимах `"water"`, `"ground"`, `"air"` (переключение между режимами через `switch_mode`).

Тогда:

| Режим | river | tree | wall |
|---|---|---|---|
| water | True | False | False |
| ground | False | True | False |
| air | True | True | True |

## 5. Граничные случаи

1. **Энергия ровно на пределе.** `energy` равна стоимости `switch_mode` или затратам `move` — действие разрешено, энергия становится 0.
2. **Масса ровно на пределе плавучести.** `mass_kg == hull_volume_m3 * 1000` — транспорт плавает.
3. **Переключение в тот же режим.** Ничего не меняется, энергия не тратится.
4. **Переполнение при заправке.** `refuel` не поднимает `energy` выше 100.
5. **Ошибка не портит состояние.** После любого исключения `energy`, `position_km` и `mode` остаются прежними.

## 7. Что вне рамок

- Реальная физика: вес топлива, сопротивление, ветер, течение, высота полёта.
- Взлёт и посадка как отдельные процессы: полёт — это просто режим.
- Повреждения и износ, разгрузка и погрузка.
- Несколько пилотов, карта, координаты (только пройденный путь `position_km`).
- Потоки и параллельная работа с одним объектом.
- Проверка типов аргументов (считаем, что вызывающий передаёт `str` и числа).
